# FSPI 车辆控制模块

## 概述

FSPI 车辆控制模块是一个独立的程序，专门用于通过 SPI 协议控制车辆运动。该模块与图像识别系统完全分离，可以独立运行和调试。

## 项目结构

```
fspi/
├── csrc/                    # 源代码目录
│   ├── fspi_module.c       # FSPI底层驱动实现
│   └── main.c              # 车辆控制主程序
├── include/                 # 头文件目录
│   └── fspi_module.h       # FSPI模块接口定义
├── build/                   # 编译输出目录
└── Makefile                # 编译配置文件
```

## 功能特性

- **独立的车辆控制程序**：完全脱离图像识别逻辑
- **实时交互控制**：支持键盘实时控制车辆运动
- **预设测试序列**：内置车辆运动测试程序
- **错误重试机制**：具备通信失败自动重试功能
- **资源管理**：完善的初始化和清理机制

## 支持的控制命令

| 按键 | 功能 | 说明 |
|------|------|------|
| W/w  | 前进 | 车辆向前运动 |
| S/s  | 后退 | 车辆向后运动 |
| A/a  | 左转 | 车辆向左转向 |
| D/d  | 右转 | 车辆向右转向 |
| X/x  | 停止 | 停止所有运动 |
| T/t  | 测试 | 运行预设测试序列 |
| H/h  | 帮助 | 显示帮助信息 |
| Q/q  | 退出 | 退出程序 |

## 硬件要求

- **SPI 设备**：需要 `/dev/spidev4.0` 设备文件存在
- **权限要求**：需要管理员权限访问 SPI 设备
- **硬件连接**：确保 SPI 硬件连接正常

## 使用说明

1. **启动程序**：
   ```bash
   make run
   ```

2. **交互控制**：
   - 程序启动后进入交互模式
   - 按相应按键控制车辆运动
   - 按任意控制键后车辆开始运动，需要手动停止

3. **测试模式**：
   - 按 `t` 键运行预设测试序列
   - 测试序列：前进2秒 → 后退2秒 → 左转2秒 → 右转2秒

4. **安全退出**：
   - 按 `q` 键或 `Ctrl+C` 安全退出
   - 程序退出前会自动停止所有车辆运动

## 技术细节

### 通信协议
- **接口**：SPI (Serial Peripheral Interface)
- **设备**：/dev/spidev4.0
- **速率**：100 MHz
- **模式**：SPI_MODE_3 (CPOL=1, CPHA=1)

### 控制地址映射
- **前进控制**：地址 0x0000
- **后退控制**：地址 0x0001  
- **左转控制**：地址 0x0002
- **右转控制**：地址 0x0003

### 容错机制
- **写入重试**：最多重试 15 次
- **读取验证**：写入后读回验证
- **延时保护**：操作间隔 10ms 延时

## 与 PCIE 程序的关系

- **完全独立**：FSPI 和 PCIE 程序互不依赖
- **并行运行**：可以同时运行两个程序
- **专业分工**：
  - FSPI 程序：专注车辆控制
  - PCIE 程序：专注图像识别

## 故障排除

### 常见问题

1. **SPI设备不存在**
   ```
   错误: FSPI Device open failed: No such file or directory
   解决: 检查硬件连接和驱动加载
   ```

2. **权限不足**
   ```
   错误: Permission denied
   解决: 使用 sudo 运行程序
   ```

3. **通信失败**
   ```
   错误: 车辆控制失败 (已重试15次)
   解决: 检查硬件连接和 SPI 配置
   ```

### 调试建议

1. **检查设备文件**：
   ```bash
   ls -l /dev/spidev*
   ```

2. **检查权限**：
   ```bash
   sudo chmod 666 /dev/spidev4.0
   ```

3. **查看系统日志**：
   ```bash
   dmesg | grep spi
   ```
