# S 与 M 的公共应用模块

两个板端工程共同引用这里的实现。复制或部署 `M`、`S` 时，同时携带这一层 `common`，保持三者为同级目录。

| 目录 | 职责 | 兼容边界 |
|---|---|---|
| `perception/include` | 车道线型与交通灯的数据结构、帧头编码、共享内存访问 | 原共享内存键、字段顺序、字节序、超时和原子操作保持不变 |
| `transport/include` | 视频 UDP 报文及帧组装 | 保留 FPV2/V3 标识、报文长度、校验和、序号与会话处理 |
| `image` | 两端共用的 RGB888 letterbox 实现 | 保留 M 端逐像素路径与 S 端既有的等比例行拷贝分支 |
| `steering` | 转向反馈线协议、平台契约和构建辅助 | 保留现有 STF1 接口与两端转向工具依赖 |

`M/include`、`S/include` 及两端 `udp/include` 内的对应头文件保留为兼容入口。应用代码仍可使用原来的 `#include` 名称；公共实现只在此目录维护一份。

本次整理没有修改模型、检测阈值、线协议或控制决策。Makefile 已增加传递头文件依赖，公共头文件更新后会触发相应对象文件重新编译。
