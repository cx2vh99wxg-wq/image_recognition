# 阶段 3：角度闭环预留

当前只有与共同 API 对应的 NOT_READY 实现，既不读取硬件，也不产生脉冲。
所有未知角度返回 NAN；不存在“目标设置成功就表示已转到”的行为。

进入本阶段的条件：A 已确认可控步长与释放行为；B 的真实测角已对照独立物理刻度验证。

后续由 A 主集成：

1. 接收绝对目标角，检查机械限位、真实中位和反馈有效性。
2. 非阻塞控制周期调用执行器，按误差缩短脉冲，支持中断和新目标。
3. 使用到位容差、稳定时间、动作超时和反向间隔，避免左右高频反打。
4. 反馈丢失、无机械响应、手动接管、STOP 等状态必须显式处理。
5. 实车默认拒绝 SIMULATED、未归零或过期反馈；测量网络延迟后设定超时。
6. 若机构自动回中，先证明能维持中间角度，再接视觉外环。

该阶段再替换原有三档估计位置，保留原有 STOP/人工接管及其他功能的优先级。
