# 弯道检测自动控制功能使用说明

## 功能概述

实现了从M端到S端再到FSPI的完整弯道检测和自动控制链路：
- **M端**：检测弯道类型（左弯/右弯/直道/S弯）并通过UDP发送
- **S端UDP**：接收弯道信息并写入共享内存
- **FSPI端**：读取弯道信息并自动控制车辆转向

## 数据流程

```
M端（发送端）
    ↓ UDP网络传输
S端UDP接收程序（udp/csrc/main.cpp）
    ↓ 共享内存写入
弯道检测共享内存（CurveDetectionSharedMemory）
    ↓ 共享内存读取
FSPI控制程序（fspi/csrc/main.c）
    ↓ 车辆控制
车辆转向执行（左转/右转/直行）
```

## 弯道类型定义

```c
typedef enum {
    CURVE_NONE = 0,    // 直道
    CURVE_LEFT = 1,    // 左弯
    CURVE_RIGHT = 2,   // 右弯
    CURVE_BOTH = 3     // S弯（左右都有）
} CurveType;
```

## 共享内存结构

```c
typedef struct {
    volatile uint32_t frame_id;        // 帧ID
    volatile uint32_t curve_type;      // 弯道类型
    volatile uint32_t confidence;      // 检测置信度（0-100）
    volatile uint32_t curve_angle;     // 弯道角度（度）
    volatile uint64_t timestamp;       // 时间戳
    volatile uint32_t writer_active;   // 写入者活跃标志
    uint8_t reserved[40];              // 预留空间
} CurveDetectionSharedMemory;
```

**共享内存key：** `0x1234567E`（SHM_CURVE_DETECTION_KEY）

## 车辆控制逻辑

### 1. 直道（CURVE_NONE）
- **动作**：停止所有转向，保持直行
- **逻辑**：
  - 如果左转处于激活状态 → 停止左转
  - 如果右转处于激活状态 → 停止右转

### 2. 左弯（CURVE_LEFT）
- **动作**：向左转
- **前提条件**：置信度 ≥ 60%
- **逻辑**：
  - 停止右转（如果有）
  - 启动左转
  - 更新左转计时器（用于超时保护）

### 3. 右弯（CURVE_RIGHT）
- **动作**：向右转
- **前提条件**：置信度 ≥ 60%
- **逻辑**：
  - 停止左转（如果有）
  - 启动右转
  - 更新右转计时器（用于超时保护）

### 4. S弯（CURVE_BOTH）
- **动作**：保持当前转向状态
- **逻辑**：不做任何改变，谨慎通过

## 启动顺序

**重要：必须按照以下顺序启动程序，否则共享内存初始化会失败！**

1. **启动M端发送程序**
   - 检测弯道并通过UDP发送数据

2. **启动S端UDP接收程序**
   ```bash
   cd S/udp
   ./app
   ```
   - 接收UDP数据
   - 写入弯道检测共享内存

3. **启动FSPI控制程序**
   ```bash
   cd S/fspi
   sudo ./app
   ```
   - 读取弯道检测共享内存
   - 自动控制车辆转向

## 控制参数

### 置信度阈值
- **默认值**：60%
- **作用**：只有当弯道检测置信度 ≥ 60% 时才执行转向
- **目的**：避免误判导致的错误转向

### 转向超时
- **默认值**：0.5秒
- **作用**：转向动作持续0.5秒后自动重置
- **目的**：防止转向卡死

### 检测周期
- **默认值**：100ms（每秒检测10次）
- **路况打印**：每1秒打印一次当前路况
- **变化触发**：路况变化时立即执行控制

## 故障排查

### 问题1：弯道检测共享内存初始化失败
**原因**：S端UDP程序未启动或已退出
**解决**：先启动S端UDP程序，再启动FSPI程序

### 问题2：车辆不转向
**可能原因**：
1. 置信度低于60% → 检查M端检测准确度
2. 转向超时 → 正常现象，超时后会自动重新启动
3. 手动控制覆盖 → 检查是否有手动发送0xCC/0xDD指令

### 问题3：车辆转向异常频繁
**可能原因**：路况检测不稳定
**解决**：可以提高置信度阈值（在main.c第562行和596行修改）

## 性能优化建议

1. **置信度阈值调整**
   - 赛道平整：可降低至50%
   - 赛道复杂：建议提高至70%

2. **检测周期调整**
   - 高速行驶：建议缩短至50ms
   - 低速行驶：可延长至200ms

3. **转向超时调整**
   - 急弯：可缩短至0.3秒
   - 缓弯：可延长至1.0秒

## 注意事项

1. **优先级**：弯道自动控制的优先级低于手动控制和紧急制动
2. **安全性**：设置了置信度阈值，避免误判
3. **稳定性**：使用了状态跟踪和防抖动机制
4. **兼容性**：不影响原有的手动控制功能
