# M 端转角反馈发送入口（待实现）

职责：把 M 端测得的方向盘角度和角速度编码为公共 STF1 帧，通过独立 UDP 数据流发送给 S。
本目录当前只有接入说明，没有已工作的发送器；现有视频 UDP 程序尚未修改。

```text
M/imu/csrc：采样、标定、测角
    ↓ 真实且有效的转角与采样时间
M/imu/feedback：STF1 编码、UDP 发送（待实现）
    ↓ M→S
S/steering/feedback：解码、新鲜度/会话校验（待实现）
    ↓
S/steering/controller：角度闭环（待实现）
```

- 共同头和编码器使用 `common/steering/contracts/`，不复制 S 端源文件。
- 只在新样本到达时推进序号；重复发送不刷新原样本年龄。
- 保留真实/模拟、有效性及机械中位基准状态；台架相对积分不能自动标成已归零。
- 与视频发送解耦，不把实际方向盘角度塞入原来的弯道估计 `curve_angle`。
- 双方联调时统一目标端口、超时与会话切换规则，并测量端到端延迟。
